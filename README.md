## ✨ Features

- **Hero & Storytelling Showcase:** Dynamic visual showcase with real images of the restaurant, lawn, banquet hall, and artisanal mocktails.
- **Interactive Multi-Cuisine Menu:** Filterable categories (Veg, Non-Veg, Indian, Chinese, Tandoori, Desserts, Mocktails) with direct WhatsApp quick-ordering.
- **Moments at Night Queen (Gallery):** Full categorized photo gallery with full-screen keyboard-navigable Lightbox.
- **Table & Event Reservation System:** Real-time form with guest count selection, date/time pickers, special requests, and instant WhatsApp/Direct confirmation.
- **Google Reviews & Testimonials:** Interactive testimonial slider highlighting real patron feedback and 4.4-star rating.
- **Interactive Location & Contact:** Embedded Google Maps, quick directions, one-tap calling, and social links.
- **Dark/Light Luxury Theme Toggle:** Seamless switching with polished color schemes and fluid animations powered by Motion.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
- `npm` or `pnpm` or `yarn`

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/night-queen-restaurant.git

# 2. Navigate to project directory
cd night-queen-restaurant

# 3. Install dependencies
npm install
```

### Development

```bash
# Start the local development server
npm run dev
```

Open your browser and navigate to `http://localhost:3000`.

### Production Build

```bash
# Type check and build optimized bundle for production
npm run build

# Preview production build locally
npm run preview
```
